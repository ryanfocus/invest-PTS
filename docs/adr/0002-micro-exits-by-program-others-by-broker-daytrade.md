# 微台由程式 13:25 平倉，大台、小台交給券商當沖強平

PTS 不過夜。我們只替**微台**寫出場：13:25 市價平倉。大台、小台標記當沖，由券商在 13:30 自動平倉，程式不送出場單。這樣做的原因是微台不能標當沖（作者的說法），沒有券商會幫它平倉。

## Considered Options

- **三個商品都由程式在 13:25 平倉**：做法一致，但大台、小台會有兩套出場機制同時存在。使用者選擇只保留必要的那一套（YAGNI）。
- **等到 13:30 之後再出場**：行不通。如果程式在券商強平之後才送「平倉」單，帳上已經沒有部位，那張單會變成一筆反向的新倉，而且會過夜。此外，結算日的近月合約在 13:30 就停止交易。

## Consequences

- 收盤前的時間表是：13:20 進場截止（同時取消等待中的突破進場）→ 13:25 微台平倉 → 13:30 券商當沖強平。13:25 留了 5 分鐘，足夠在 13:30 前重試三次。
- 大台、小台的出場完全依賴券商。「13:30 會強平」和「微台不能當沖」都是作者的說法，上線第一天要看一次帳戶確認。
- 交易微台時，如果程式在盤中當掉，就沒有任何機制會平倉，需要另外設計備援。交易大台、小台時，券商的強平本身就是備援。
