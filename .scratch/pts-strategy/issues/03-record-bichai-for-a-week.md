# 03: 【實機】錄一週筆差

**What to build:** 用 02 的盤中程式在真實交易日跑至少 5 個交易日，回答規格留下的筆差事實問題。策略的核心指標靠這些答案才能確定沒有算反。

**Blocked by:** 02

**Status:** ready-for-human

- [ ] 筆差的正負方向：大漲的時段，筆差（成交賣出筆數減成交買進筆數）是不是正的。如果相反，回報開發端調整定義。
- [ ] 累計起點：群益給的累計成交筆數是從 08:45 開始算，還是包含夜盤。
- [ ] 每天筆差超過 ±1000 的分鐘數，以及筆差跳增（±100）出現的次數。拿來對照作者說的「最近比較常不會進單」。
- [ ] 結果寫在這張 ticket 底下的 `## Comments`。
