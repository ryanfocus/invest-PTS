# 11: 【實機】上線驗收

**What to build:** 打開自動下單之前，把規格「上線前的實機驗證」清單逐項做完。這些都需要真實連線與真實交易日，測試涵蓋不到。

**Blocked by:** 05, 07, 10

**Status:** ready-for-human

- [ ] 模擬模式跑至少一週：模擬出來的進場時間點，和策略作者的判斷一致。
- [ ] RSI 對數字：挑一天，拿程式算出的 RSI 和看盤軟體核對。
- [ ] 昨收對數字：連續幾天，拿程式取得的昨收和期交所「一般」時段收盤價核對。
- [ ] 即時回報：找一個 OS 有下單的交易日，確認盤中即時回報會同時送到 PTS 和 OS，兩者同時登入互不干擾（規格第 57 條）。
- [ ] 成交查詢的欄位位置：PTS 第一次真實成交後取回委託與成交查詢，核對大台、小台的成交列，以及標了當沖的列（微台單腳已由 invest-os 驗證過；出場不確定時的查詢依賴這一點）。
- [ ] 第一次真實下單之後，13:30 看一次帳戶：確認券商的當沖強平真的平掉了大台／小台；確認微台確實不能標當沖。
- [ ] 小口數起步：每次進場 1 口、加碼上限調低，跑一段時間再放大。
- [ ] 出場程式在同一個行程裡第二次呼叫群益登入（13:25 網路類的登入失敗之後每分鐘重登）：元件回什麼代碼、能不能登入成功。
- [ ] 每一項的結果寫在這張 ticket 底下的 `## Comments`。
