# 07: 下單失敗：拒單與成交不確定

**What to build:** 進場委託出問題時，程式要分清楚兩種處境並正確收手：委託被拒（確定沒有部位），以及委託送出去了卻收不到成交回報（可能有部位）。兩種情況當天都停止進場，並發出講清楚「你要做什麼」的 Discord。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 委託被拒（確定沒送出去）：當天不再進場；Discord 只發一次，附上原因，例如保證金不足、憑證問題（規格第 51 條）。
- [ ] 委託送出去但收不到成交回報：部位檔記為「不確定」，當天不再進場，發 Discord 請使用者確認帳戶（規格第 50 條前半）。
- [ ] 送出之後發生的任何意外（逾時、元件壞掉）都算「送出去但不知道成交」，絕不可以當成「沒送出去」。
- [ ] 告警用固定的說法分辨三種處境：「委託沒有送出去」「委託送出去了，但…」「部位還在」（規格第 41 條）。
- [ ] 測試：拒單後當天停止、告警只發一次；不確定後當天停止、部位檔狀態正確。
