# 09: 可靠度：心跳、報價中斷、重啟恢復

**What to build:** 讓 PTS 在出狀況時有人知道、也能自己接續：盤中程式沒跑的話，出場程式會發現；報價中斷時停止進場並告警；盤中程式當掉被重啟後，從部位檔接續當天的狀態。

**Blocked by:** 06, 08

**Status:** ready-for-agent

- [ ] 盤中程式啟動後每分鐘更新心跳記錄（交易日、最後存活時刻）。
- [ ] 出場程式在交易日發現今天沒有心跳，發 Discord（規格第 54 條）。
- [ ] 報價中斷期間不進場；連續中斷 3 分鐘發 Discord（規格第 53 條）。
- [ ] 盤中重啟後：從部位檔恢復已成交的口數與交易商品；補回當天已經過去的 1 分 K 再繼續判斷；等待中的突破進場不恢復（規格第 48 條）。
- [ ] 重啟時如果設定檔的商品已經被改掉，仍沿用部位檔的商品（規格第 43 條）。
- [ ] 測試：心跳缺失告警；中斷期間不進場、超過 3 分鐘告警；重啟後恢復的口數與商品正確。
